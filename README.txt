SWEA Session Keeper

설치 방법
1. Chrome 주소창에 chrome://extensions 입력
2. 오른쪽 위 '개발자 모드' 켜기
3. '압축해제된 확장 프로그램을 로드합니다' 클릭
4. 이 폴더(swea-session-keeper)를 선택
5. SWEA에 로그인합니다. 로그인 후에는 SWEA 탭을 열어둘 필요가 없습니다.

사용 방법
- 확장 프로그램 아이콘을 클릭합니다.
- 상태를 ON으로 둡니다.
- 요청 간격을 선택합니다. 기본값은 5분입니다.
- '지금 요청 보내기'로 즉시 테스트할 수 있습니다.

동작 방식
- 서비스 워커에서 https://swexpertacademy.com/main/main.do로 직접 fetch 요청을 보냅니다.
- SWEA 탭이 없어도 설정한 간격으로 요청하며, '지금 요청 보내기'도 같은 방식으로 즉시 요청합니다.
- 요청 주소에 _swea_keep_alive 값이 붙고, cache: "no-store"로 요청합니다.
- credentials: "include"로 로그인 쿠키를 포함하도록 요청합니다. SWEA 로그인 상태여야 합니다.
- 응답 URL에 login이 포함되거나 응답 HTML에 비밀번호 입력란이 있으면 '세션 만료 또는 로그인 필요'로 표시합니다.
- 그 외에는 실제 HTTP 상태 코드에 따라 요청 성공 또는 실패를 표시하고, 요청 시각과 결과를 저장합니다.
- 절전/잠금 해제 후 Chrome의 idle 상태가 active로 바뀌면 즉시 요청합니다. 상태가 OFF이면 요청하지 않습니다.
- 서버가 idle timeout을 요청 기준으로 갱신한다면 로그인 유지에 도움이 됩니다.

주의
- SWEA 서버가 absolute timeout(로그인 후 일정 시간이 지나면 무조건 만료)을 사용하면 이 확장 프로그램으로 막을 수 없습니다.
- 사이트 정책이나 세션 처리 방식이 변경되면 동작하지 않을 수 있습니다.
